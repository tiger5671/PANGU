# Official firmware source portals

These vendor support/download entry points were reviewed on 3 November 2026. They are references for finding product firmware, not verified links to the 42 exact evaluated binaries. No firmware was downloaded to establish version availability.

| Vendor | Official entry point | Reference and notes |
| --- | --- | --- |
| Cisco | [Support/download portal](https://software.cisco.com/download/home) | [Official reference](https://software.cisco.com/download/static/assets/i18n/help.html). Software download portal; the portal may redirect to Cisco sign-in. |
| D-Link | [Support/download portal](https://support.dlink.com/) | Search by model; the support page also links to its legacy-product site. |
| H3C | [Support/download portal](https://www.h3c.com/cn/Service/Document_Software/Software_Download/) | Official Chinese software-download entry point. |
| Linksys | [Support/download portal](https://support.linksys.com/) | [Official reference](https://support.linksys.com/kb/article/101/). The linked official guide explains model-specific firmware downloads. |
| Mercury | [Support/download portal](https://service.mercurycom.com.cn/) | Official service portal with a download-center entry. |
| NETGEAR | [Support/download portal](https://www.netgear.com/support/download/) | Redirects to the vendor download application; no exact binary was checked. |
| Tenda | [Support/download portal](https://www.tendacn.com/download/) | Official global download center. |
| TOTOLINK | [Support/download portal](https://m.totolink.net/portal/list/index/id/5.html) | Official mobile download center with model search. |
| TP-Link | [Support/download portal](https://www.tp-link.com/en/support/download/) | Official global download center. |
| TRENDnet | [Support/download portal](https://www.trendnet.com/support/) | Official product-support portal. |
| Ubiquiti | [Support/download portal](https://ui.com/download) | Official software portal; historical releases are not guaranteed to remain available. |
| WAVLINK | [Support/download portal](https://www.wavlink.com/zh_cn/Firmware.html) | Official Chinese firmware search page. |
| Zyxel | [Support/download portal](https://www.zyxel.com/global/en/support/download) | Official global download library. |

Search using the inventory model, hardware/region revision, and recorded firmware version. Historical releases may be unavailable. Exact archive URLs, filenames, binary SHA-256 values, and acquisition dates should be recorded from the actual files and acquisition records if they are added later.

The [inventory notes](README.md) explain which identifiers are available and which source model/version annotations remain unresolved.
